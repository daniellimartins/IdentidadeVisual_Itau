# 🎨 Identidade Visual Itaú — Figma

Projeto de estudo e exploração de identidade visual desenvolvido no **Figma**, inspirado na linguagem visual da marca Itaú.

O objetivo deste projeto foi analisar e reproduzir elementos visuais da identidade da marca, explorando composição, cores, tipografia, formas e aplicações em diferentes peças.

> ⚠️ **Aviso:** Este é um projeto de estudo e não possui vínculo oficial com o Itaú. Todos os direitos relacionados à marca e aos seus elementos pertencem aos respectivos proprietários.

---

## 📌 Sobre o projeto

A proposta foi desenvolver uma interpretação da identidade visual do Itaú utilizando o Figma como principal ferramenta de criação.

Durante o processo, foram explorados:

- 🎨 Paleta de cores
- 🔤 Tipografia
- 🟧 Formas e elementos gráficos
- 📐 Grid e composição
- 🖼️ Aplicações da identidade visual
- 📱 Composições para interfaces e materiais digitais

---

## 🎨 Identidade visual

### Cores

| Cor | Hex |
|---|---|
| Azul | `#EC7000` |
| Azul escuro | `#003B70` |
| Branco | `#FFFFFF` |
| Preto | `#000000` |

> Os valores acima são utilizados apenas como referência para este estudo e podem não representar integralmente os padrões oficiais atuais da marca.

### Tipografia

A tipografia foi escolhida considerando características visuais semelhantes às utilizadas na comunicação da marca, buscando manter consistência entre títulos, textos e elementos de interface.
